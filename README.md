# KingsNigus Academy

**Powered by the SkillBridge Learning OS**

> **Think Deeply. Create Boldly. Lead Wisely.**

KingsNigus Academy is an emerging STEM learning institution designed to help learners move beyond course completion toward demonstrated capability, meaningful creation, trusted evidence, opportunity, leadership, and impact.

**Live platform:** https://www.kingnigusacademy.com

---

## Mission

**KingsNigus Academy exists to transform learning into capability, capability into creation, and creation into opportunity.**

## Vision

**A world where every motivated learner can develop the knowledge, capability, creativity, and evidence needed to solve meaningful problems and create a better future.**

## Institutional Promise

> **At KingsNigus Academy, learning should result in something you can understand, explain, apply, create, and prove.**

Our transformation model is:

```text
Knowledge → Capability → Creation → Evidence → Opportunity → Impact
```

---

# Why KingsNigus Exists

Access to information is no longer enough.

Traditional learning often ends with content delivery, tests, grades, or certificates. KingsNigus is being designed around a different question:

> **What can the learner actually understand, apply, create, explain, and prove?**

The learner—not the course—is the central educational outcome.

A KingsNigus learner should increasingly be able to say:

> **I understand it. I can use it. I created something with it. Here is the evidence.**

## Core Institutional Components

### KingsNigus Academy
The public institution, brand, mission, governance, partnerships, and academic identity.

### SkillBridge Learning OS
The educational methodology that describes how learner capability develops:

```text
Learn → Practice → Build → Master → Apply → Create → Lead
```

### Luminery AI
An intelligent learning mentor designed to strengthen thinking rather than replace it. Luminery supports explanation, questioning, hints, practice, reflection, project feedback, and increasingly challenging reasoning.

### Pyravanta
The learner capability and pathway intelligence layer. Pyravanta is designed to help answer:

> **Where is this learner now, and where should they go next?**

It connects skill evidence, capability status, learning recommendations, projects, portfolio growth, and future opportunity readiness.

# Curriculum Philosophy

Every KingsNigus curriculum should be designed backward from demonstrated capability and forward toward meaningful creation, evidence, and opportunity.

A major lesson may follow a progression such as:

```text
Situation
→ Explore
→ Understand
→ Represent
→ Reason
→ Practice
→ Model
→ Apply
→ Code / Tool
→ Create
→ Reflect
→ Evidence
```

For mathematics in particular, learners should not only solve mathematics. They should represent it, reason about it, model with it, interpret it, test it, create with it, and communicate what it means.

A mathematics concept should increasingly connect:

```text
Real Situation
↕
Words
↕
Equation
↕
Table
↕
Graph
↕
Code
↕
Interpretation
```

# Capability-Based Progression

KingsNigus advancement is based on demonstrated capability rather than course completion alone.

A learner can be at different stages for different skills.

Example:

```text
Linear Equations       MASTER
Functions              BUILD
Domain & Range         PRACTICE
Graph Interpretation   BUILD
Mathematical Modeling  LEARN
```

This avoids reducing a learner to one broad grade or score.

# Diagnostic & Capability Model

KingsNigus is being designed to determine learner status through demonstrated evidence at the skill level.

Diagnostic work may examine:

- conceptual understanding
- procedural accuracy
- reasoning
- representation
- error analysis
- real-world application
- transfer
- creation
- independence

The current capability model considers dimensions such as:

| Dimension | Initial Weight |
|---|---:|
| Conceptual Understanding | 20% |
| Practice / Accuracy | 15% |
| Mathematical / Logical Reasoning | 20% |
| Real-World Application | 15% |
| Independent Performance | 10% |
| Creation / Project Evidence | 15% |
| Reflection & Communication | 5% |

These are design weights, not immutable rules. Future learner evidence and academic research may refine them.

A score alone does **not** unlock advanced stages. Higher stages require appropriate evidence.

# Assessment

KingsNigus assessment asks:

> **What does the learner actually understand, what can they do independently, and what evidence proves it?**

Assessment is designed around multiple layers:

```text
Diagnostic
→ Formative
→ Mastery
→ Application
→ Creation
→ Reflection / Defense
```

Mastery should require more than high routine accuracy. It should include understanding, reasoning, independence, explanation, and consistency.

Application requires transfer into unfamiliar or authentic situations.

Create requires original evidence.

Lead requires strong capability plus communication, contribution, defense, mentoring, or responsible leadership.

Retakes and revision are part of learning:

```text
Attempt → Feedback → Revision → New Evidence → Improved Capability
```

# AI Assistance & Independence

KingsNigus does not assume that all AI use is cheating.

The principle is:

> **AI use is not automatically a weakness. Hidden AI dependence is.**

Important evidence may record assistance levels such as:

```text
Independent
Minimal Hints
Guided
AI Collaborative
Highly Assisted
```

Learners should disclose significant AI assistance and remain responsible for understanding, explaining, and defending their work.

# Credentials & Capability Transcript

KingsNigus distinguishes among:

- **Completion Certificates** — confirm required course completion
- **Capability Credentials** — recognize specific demonstrated capabilities
- **Capability Transcript** — a living record of verified skills, evidence, projects, independence, growth, and readiness

The long-term trust model is:

```text
Claim → Evidence → Verification
```

A learner should not be able to purchase mastery. Credentials should follow evidence.

> **Don't just show what you completed. Show what you can do.**

KingsNigus does not claim accreditation, diploma authority, university credit, or professional licensing unless and until such recognition is actually obtained.

# Research & Innovation

KingsNigus aims to make research a habit of thinking rather than something reserved only for graduate school.

The progression begins with:

```text
Observe → Question → Investigate → Analyze → Explain
```

and can advance toward:

```text
Question
→ Background
→ Method
→ Evidence
→ Analysis
→ Interpretation
→ Limitations
→ Communication
→ New Questions
```

Innovation follows disciplined investigation:

```text
Observe
→ Define Problem
→ Research
→ Ideate
→ Design
→ Prototype
→ Test
→ Learn
→ Improve
→ Validate
→ Communicate
→ Deploy / Scale
```

Students should generally retain appropriate ownership of original work they create unless a clear, fair written agreement establishes otherwise.

KingsNigus should credit creators, disclose AI assistance, respect community knowledge, and handle serious intellectual-property questions responsibly.

# Local Development

## Prerequisites

Install a current Node.js and npm environment.

## Clone

```bash
git clone https://github.com/nigussie29/SkillBridgeAcademy.git
cd SkillBridgeAcademy
```

## Install dependencies

```bash
npm install
```

## Configure environment variables

Copy `.env.example` to `.env` and provide your Supabase values:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_PUBLIC_KEY
```

Do not commit real secrets.

## Run locally

```bash
npm run dev
```

## Production build

```bash
npm run build
```

## Preview build

```bash
npm run preview
```
