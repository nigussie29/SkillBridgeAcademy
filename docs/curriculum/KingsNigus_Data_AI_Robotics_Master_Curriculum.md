# KingsNigus Academy
## School of Data, Artificial Intelligence & Robotics
### Master Curriculum Blueprint - Version 1.0

**Model. Engineer. Learn. Build. Deploy. Solve.**

> **Think Deeply. Create Boldly. Lead Wisely.**

This curriculum is designed for mathematically prepared learners who already possess substantial knowledge of algebra, calculus, probability, statistics, vectors, matrices, and quantitative reasoning. It is not a collection of beginner tutorials. Its purpose is to develop market-ready and future-ready professionals who can model real problems, engineer trustworthy data systems, build and evaluate intelligent systems, integrate software with physical systems, validate results, deploy reliable solutions, and demonstrate evidence of professional capability.

> **Curriculum design principle:** Where it came from -> What it means -> How it works -> How we compute it -> Where we use it -> What we create -> What remains unsolved.

---

## 1. School Mission

The KingsNigus School of Data, Artificial Intelligence & Robotics develops mathematically grounded, software-capable professionals who can transform data into intelligence, intelligence into reliable systems, and intelligent systems into solutions for real human and societal problems.

The School is organized around a connected progression:

```text
Mathematical Model
        ->
Data Collection
        ->
Data Engineering
        ->
Statistical Analysis
        ->
Machine Learning
        ->
AI Decision System
        ->
Sensors / Robotics
        ->
Control and Action
        ->
Deployment
        ->
Monitoring
        ->
Validation
        ->
Impact
```

### Core curriculum rules

1. No syntax without application.
2. No application without reasoning.
3. No project without engineering standards.
4. No course without evidence of capability.
5. No pathway is finished until the learner can perform the work.
6. Important concepts must be connected backward to prior knowledge and forward to professional systems.
7. Students must learn both how systems succeed and how they fail.
8. Market readiness and research readiness are explicit outcomes.

## 3. Graduate Capability Profile

A graduate should be able to receive a real business, engineering, research, or societal problem and:

- translate it into a mathematical or computational model;
- identify assumptions, constraints, uncertainty, and limitations;
- acquire, transform, validate, and model data;
- design data pipelines and analytical architectures;
- create reliable software rather than notebook-only prototypes;
- train, evaluate, explain, and monitor machine-learning models;
- build evaluated AI applications and agentic systems with appropriate safeguards;
- integrate sensing, estimation, planning, control, and AI in robotic systems;
- use Git, testing, APIs, containers, documentation, observability, and maintainable architecture;
- design experiments and conduct reproducible research;
- communicate architecture, tradeoffs, risks, results, and recommendations;
- defend technical decisions using evidence.

The intended graduate does not merely say:

> "I know Python," "I know Power BI," or "I know machine learning."

The intended graduate can say:

> **I can understand the problem, model the system, engineer the data, build the software, evaluate the intelligent component, deploy or integrate the solution, diagnose failures, communicate my decisions, and show evidence that I can do the work.**

## 4. Connected Knowledge Architecture

The curriculum deliberately shows how ideas grow rather than treating courses as isolated subjects.

A signature mathematical connection is:

```text
y = ax + b
    -> multivariable linear models
    -> vector form: y = w^T x + b
    -> matrix form: y = X beta + epsilon
    -> estimation and least squares
    -> optimization and gradients
    -> dynamical systems: dx/dt = f(x,u,t)
    -> neural layer: h = sigma(Wx + b)
    -> deep learning
    -> transformers
    -> autonomous intelligent systems
```

# 6. Year 1 Detailed Course Map

## DAIR-101 - Mathematical & Computational Modeling

### Professional purpose

Use mathematics as a working language for real systems and connect classical mathematical modeling to simulation, data, parameter estimation, optimization, machine learning, AI, and robotics.

### Module sequence

1. Model formulation: variables, assumptions, dimensions, constraints and objectives
2. Linear and matrix models; least squares as geometry and estimation
3. Difference equations and discrete-time systems
4. Ordinary differential equations and dynamical systems
5. Numerical methods for simulation and approximation
6. Parameter estimation, optimization and inverse problems
7. Sensitivity, uncertainty and identifiability
8. Model validation, comparison and failure analysis

### Primary tools

Python, NumPy, SciPy, Pandas, Matplotlib, Jupyter, Git.

### Professional project

**Disease Spread Computational Modeling**

Students progress from SIR to SEIR models, simulate scenarios, estimate parameters from data, quantify uncertainty, compare assumptions, test sensitivity, and defend the limits of the model.

### Required evidence

- Mathematical formulation
- Simulation notebook
- Parameter-estimation workflow
- Sensitivity analysis
- Validation report
- Technical presentation

### Connections

```text
Algebra -> matrix models
Calculus -> rates of change
Differential equations -> dynamic systems
Statistics -> parameter uncertainty
Optimization -> fitting models
AI -> model comparison and hybrid methods
```

### Market-readiness questions

- How do you decide whether a model is too simple or unnecessarily complex?
- What makes a parameter identifiable?
- How would you validate a disease-spread model against observed data?
- When should a mechanistic model be preferred to a purely data-driven model?

---

## DAIR-102 - Professional Python & Software Engineering

### Professional purpose

Move from scripts and notebooks to maintainable, testable, reusable software used in data, AI and robotics systems.

### Required evidence

- Code review notes

### Market-readiness questions

## DAIR-103 - SQL, Databases & Data Modeling

### Professional purpose

Design relational and analytical data structures and use SQL as a professional language for reliable retrieval, transformation and modeling.

1. Relational theory, keys, constraints and normalization
2. Advanced querying: joins, CTEs, subqueries and window functions
3. Transactions, isolation and data integrity
4. Indexes, execution plans and performance reasoning
5. Dimensional modeling: facts, dimensions and grain
6. Slowly changing dimensions and historical analysis
7. Data quality, referential integrity and auditability
8. Warehouse-oriented SQL patterns

### Professional project

Design and implement an enterprise sales warehouse with staging, fact/dimension tables, quality rules, historical handling, and analytical queries.

### Required evidence

- ERD
- DDL
- Transformation SQL
- Quality checks
- Performance analysis
- Analytical query portfolio

# 8. Year 2 Detailed Direction

## DAIR-201 - Statistical Learning

Statistics is connected directly to modeling rather than reviewed as an isolated prerequisite.

Core progression:

```text
Probability
    -> likelihood
    -> estimation
    -> regression
    -> classification
    -> uncertainty
    -> validation
    -> statistical learning
```

Topics include linear and logistic regression, regularization, sampling, cross-validation, calibration, uncertainty, experimental design, statistical versus practical significance, and model criticism.

---

## DAIR-202 - Machine Learning Engineering

Algorithms include linear models, trees, random forests, gradient boosting, clustering, dimensionality reduction and anomaly detection.

The course is organized around the engineering lifecycle:

```text
Problem Definition
    -> Data
    -> Features
    -> Training
    -> Validation
    -> Testing
    -> Deployment
    -> Monitoring
```

Professional concerns include leakage, imbalance, drift, reproducibility, explainability, cost-sensitive decisions and failure analysis.

---

## DAIR-203 - Optimization for Data, AI & Robotics

Topics include gradients, constrained optimization, convexity, linear programming, nonlinear optimization, stochastic optimization, regularization and numerical tradeoffs.

Connections:

```text
Optimization
    -> Machine Learning
    -> Neural Networks
    -> Logistics
    -> Resource Allocation
    -> Robotics
    -> Control
```

## DAIR-204 - Deep Learning

The course begins from familiar mathematical structure:

```text
y = ax + b
    -> y = Wx + b
    -> h = sigma(Wx + b)
    -> multilayer networks
    -> backpropagation
    -> deep representation learning
```

Topics include neural computation, activations, losses, gradient descent, backpropagation, initialization, normalization, regularization, convolutional networks, sequence models and representation learning.

Primary implementation platform: PyTorch.

---

## DAIR-205 - AI Engineering & Generative AI

Topics include embeddings, transformers, attention, inference, structured output, retrieval-augmented generation, vector search, tool use, agents, evaluation, guardrails, latency, cost and observability.

Students learn that a chatbot demonstration is not equivalent to a reliable AI engineering system.

---

## DAIR-206 - AI Safety, Evaluation & Responsible Systems

Topics include hallucination, bias, uncertainty, adversarial behavior, prompt injection, privacy, explainability, evaluation, human oversight and governance.

Students must test failure conditions rather than report only successful demonstrations.

```text

    -> differential equations
    -> state-space models
    -> feedback
    -> control
```

```text
x_dot = A x + B u

```
